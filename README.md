# Hi, I'm Fabrizio Palladino

I'm a senior front-end developer and design-systems engineer based in Brussels. I've built front ends for EU institutions and large organisations since 2016, as a freelancer through my own company. I work on design systems, accessible interfaces, and the connection between design and development.

I enjoy understanding how people work, designing systems that make their work easier, and staying close to building the solution.

## Front-end and design systems

Since 2020 I've worked on the Council of the EU's public website. I created its design system from scratch: a library of web components, installable via npm, used by the Council's website and by two other teams. There I also introduced a component-based approach to the site's design and development, wrote guidelines the designers adopted, and helped editors build pages from reusable components.

The work I care about connects:

- **Design and development:** shared component models and clearer collaboration.
- **Accessibility and usability:** semantic HTML, CSS, and interfaces people can use.
- **Front-end architecture:** reusable components and maintainable JavaScript and TypeScript.

## Working with AI agents

I use coding agents in my client work. I built a small tool that takes a ticket, has an agent investigate the codebase and return a plan in a fixed format, implements it one task at a time, and runs the project's own checks. Nothing is accepted without my review, and commits stay manual. Its first batch was accessibility tickets on the Council's website.

I've also built a personal job-search tool with TypeScript and Node.js. It stores job postings, assesses them against a local profile, and helps draft applications grounded in my experience, with every statement traced back to it.

What interests me is where agents are useful, how to check their output, and which decisions should stay with the person using them.
